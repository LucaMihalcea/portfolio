# Luca Mihalcea — Portfolio

Static portfolio website, ready to publish with GitHub Pages. The site, CVs, portrait, project image, and elevator pitch video are kept together in this repository.

## Publish with GitHub Pages

1. Create a GitHub repository named `portfolio` and push this folder to its `main` branch.
2. In the repository, open **Settings → Pages** and set the publishing source to **GitHub Actions**.
3. The workflow in `.github/workflows/pages.yml` will publish the site on the next push. Future pushes to `main` will publish automatically.

The published address will be `https://<your-github-username>.github.io/portfolio/`.

## Run locally

Open `index.html` in a browser. The site uses relative paths for its local images, CVs, and video.
